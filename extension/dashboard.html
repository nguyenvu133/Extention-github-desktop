CÁCH 3 — TOKEN PAT

Tạo token tại github.com → Settings → Developer settings → Personal access tokens → Generate new token. Cần scope repo + read:user.

Token bắt đầu bằng ghp_… (classic) hoặc github_pat_… (fine-grained). Không dán email hay mật khẩu vào đây — GitHub không cho app khác nhập mật khẩu.
